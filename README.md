# Hospital Management System (HMS)

A comprehensive web-based Hospital Management System developed using **Python & Django Framework**. The platform automates day-to-day operations including patient registration, doctor appointments, diagnosis tracking, and automated discharge billing generation.

---

## 🚀 Key Features

### 👨‍💼 Admin Module
- Approve/Reject registered Doctor and Patient accounts.
- Manage beds, departments, and doctor list.
- View total patient count, pending approvals, and total financial collection.

### 👨‍⚕️ Doctor Module
- View assigned patient appointments.
- Add patient diagnosis, symptoms, and discharge recommendations.
- Manage profile and consultation status.

### 🩺 Patient Module
- Book online appointments with specific doctors.
- Track appointment approval status in real-time.
- View admit status and download itemized discharge bill receipt.

### 💳 Billing & PDF Generation
- Automatic calculation of room charges, doctor fees, and medicine costs.
- Instant PDF discharge receipt generation with Unicode UTF-8 character encoding (₹ currency symbol support).

---

## 🛠️ Tech Stack

- **Backend:** Python 3, Django Web Framework
- **Frontend:** HTML5, CSS3, JavaScript, Bootstrap (Ocean Blue Custom Theme)
- **Database:** SQLite3
- **PDF Engine:** `xhtml2pdf`
